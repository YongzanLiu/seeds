# SEEDS Lab visual identity

The current symbol contains a horizontal well with three parallel elongated
hydraulic-fracture surfaces in a translucent middle reservoir layer. The
nearest, leftmost fracture clearly extends into the exposed reservoir volume.
Interior portions of the other two fractures are occluded by the opaque upper
layer, following the same isometric view. The rounded thin surfaces retain
smooth cyan/green/yellow/orange field-like coloring.

This is a conceptual brand illustration, not a numerical result, quantitative
field map, or exact PKN solution.

The selected transparent source is `images/branding/seeds-reservoir-symbol-v6.png`.
It was refined with the built-in image generation tool; the final prompt is
`design-prompt-v6.txt`. The preceding version and its prompts remain available.
The user-supplied geometry reference is `fracture-shape-reference.png`.

The generated source is preserved unchanged. Favicon exports fit visible alpha
bounds (alpha >= 128) to a square with 10% overall padding and preserve interior
transparency. PNG variants are 32, 180 and 192 pixels. The ICO contains
16, 32, 48, 64, 128 and 256 pixel variants. `images/icon.png` is the compatibility copy.

All active favicon filenames contain `v6`. Their global links are in
`_includes/meta.html`. Earlier versions are retained and unreferenced by the head.
